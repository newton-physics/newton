Remove `newton.sensors.SensorTiledCamera`, deprecated in Newton 1.7. Migrate to `newton.sensors.SensorCamera`, which renders one view per entry of a flat `camera_transforms` array instead of a `(camera_count, world_count)` grid. Generate shared `(height, width, sample_count, 2)` rays with the static `SensorCamera.compute_camera_rays_*()` helpers, pass a `world_indices` entry per view to select its world (repeat an index for several cameras in one world), allocate outputs of shape `(view_count, height, width)` with `SensorCamera.allocate_image_*()`, and convert outputs for display with `SensorCamera.Utils.to_rgba_from_*()`. See the 1.7 deprecation entry in `CHANGELOG.md` for the full mapping.

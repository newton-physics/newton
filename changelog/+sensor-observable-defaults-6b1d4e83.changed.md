Default `SensorIMU(request_state_attributes=...)` and `SensorContact(request_contact_attributes=...)` to `False`, completing the default migration announced in Newton 1.7: sensors constructed without these arguments no longer request the deprecated `State.body_qdd` and `Contacts.force` fields or emit a `NewtonDeprecationWarning`. Allocate `solver.observables(kinds=sensor.solver_observable_kinds)` (also passing `contacts=contacts` for `SensorContact`), pass the container to `solver.step(..., observables=observables)` and to `sensor.update(..., observables=observables)`; without it, `update()` raises `ValueError` unless the deprecated field was requested separately. Explicit `True` still selects the deprecated legacy fields and emits the warning. Omit both arguments: they will be removed together with the legacy fields.

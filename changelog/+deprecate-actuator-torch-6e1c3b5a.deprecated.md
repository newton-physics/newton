Deprecate Torch checkpoints (`.pt2`, `.pt`, `.pth`) in `DriveNeuralMLP` and `DriveNeuralLSTM`, and the `allow_unsafe_torch_checkpoints` option of `ModelBuilder.add_usd()` and `parse_actuator_prim()`. Export the network with `torch.onnx.export` using dynamic batch axes, store the Newton metadata, including `model_type`, as a JSON `metadata` property of the ONNX model, and load the `.onnx` file instead; in USD, point `newton:modelPath` at it and drop `allow_unsafe_torch_checkpoints`. With ONNX checkpoints, `DriveNeuralLSTM.State.hidden` and `cell` are Warp arrays instead of Torch tensors. See the neural-network checkpoint section of the actuator guide.

Fix ``ArticulationView`` actuator parameter access for sparse world selections with a regular DOF stride, and for views whose actuator does not list its rows in replicated per-world order, which read and wrote other articulations' actuator rows; fix sparse root transform and velocity access on Python versions before 3.12. The first actuator parameter access for an actuator now builds its view mapping on the host and must happen before CUDA graph capture. A first access inside capture now raises a clear error for every layout; this is an intentional restriction, including for regular layouts whose cold capture previously returned correct values.

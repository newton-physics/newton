Name the experimental solver diagnostic API `SolverObservables`, with `SolverObservableFlags` and `solver.observables(flags)`, replacing the proposed `SolverOutputs` / `SolverResults` names. Pass the container as `observables=` to solver steps and as `solver_observables=` to sensor updates and viewer contact logging. Use `solver_observable_flags` for sensor requirements, and `OBSERVABLES_TYPE`, `SUPPORTED_OBSERVABLE_FLAGS`, and `_allocate_observables()` / `_validate_observables()` for custom solver extensions. Solver-specific container and flag types use `Observables` and `ObservableFlags`; the previous names are not retained as aliases.

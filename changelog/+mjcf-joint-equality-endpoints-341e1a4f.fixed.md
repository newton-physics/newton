Fix MJCF joint equalities that omit `joint2` or reference joints sharing a body, and joint or tendon equalities that give fewer than five `polycoef` terms. `SolverMuJoCo` now keeps the fixed-joint equality, resolves each endpoint to its own scalar MuJoCo joint instead of failing, and fills omitted polynomial terms from MuJoCo's `0 1 0 0 0` default instead of zero. Only equalities between two whole scalar joints become Newton mimic constraints; the others stay MuJoCo equality constraints, which other solvers ignore, and a `NewtonWarning` lists them. An equality naming an unknown joint raises a `ValueError` that names it.

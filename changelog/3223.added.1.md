Add experimental skinned visual mesh rendering in `SensorCamera`: UV textures, color, depth, normal and albedo output, a `deformable_surface_mode` constructor option that selects the simulation triangles, the visual meshes, or both, and a `deformable_visuals=` argument to reuse output already evaluated for a viewer.

The default constructor now loads textures on skinned meshes too. Use `load_textures=False` for depth-only rendering when texture files are unavailable.

Remove the `ModelBuilder.add_usd` arguments `legacy_angular_velocity_units` and `legacy_springref_units`, deprecated in Newton 1.7.

**Migration:**

  - Remove both keywords from import calls, even when set to `False`.
  - **Joint velocities:** Remove manual degrees-to-radians conversion after import. If an asset stored radians/s in degree-based joint-state attributes, multiply those authored values by `180 / pi`.
  - **Spring references:** Author revolute `mjc:springref` in `mjc:compiler:angle` units (degrees by default). Multiply compensated radian values by `180 / pi`.

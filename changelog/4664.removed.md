Remove the `ModelBuilder.add_usd` arguments `legacy_angular_velocity_units` and `legacy_springref_units`, deprecated in Newton 1.7. Remove both keywords from import calls, even when set to `False`. Joint-state angular velocities always convert from degrees/s to radians/s, including rotational D6 axes and merged revolute joints; remove any manual conversion of imported velocities and multiply compensated radians/s asset values by `180 / pi`. Revolute `mjc:springref` always follows `mjc:compiler:angle` (degrees by default); multiply compensated radian spring references by `180 / pi`, or select `"radian"` only when all attributes governed by that setting, including `mjc:ref`, use radians.

Add `newton.viewer.Picking` to the public API so applications with their own input handling or renderer can drag bodies with the viewer's picking spring. Call `Picking.apply_force(state)` before each solver step; it replaces the private `_apply_picking_force()` method. Read `pick_body`, `pick_point`, and `pick_target` to draw the spring, assign `pick_target` to drive it from a 3D input, and set `pick_stiffness`, `pick_damping`, and `pick_max_acceleration` to tune it, including on `viewer.picking`. The former `pick_state` and `pick_body` arrays are now internal. Optional constructor arguments are keyword-only.

Require `open3d` 0.20 or newer in the `importers` and `remesh` extras. `open3d` is now installed on Python 3.13 and newer and on Linux aarch64, but no longer on Intel macOS, where Poisson remeshing and `Gaussian.create_from_ply()` are unavailable. On Linux x86-64, these extras and the extras that include them, such as `examples` and `dev`, now require GLIBC 2.35 or newer (for example, Ubuntu 22.04), so they no longer install on Ubuntu 20.04 or RHEL 9; use a newer distribution or install Newton without these extras. Upgrade `open3d` if `Gaussian.create_from_ply()` raises an `ImportError` about the `open3d` version.

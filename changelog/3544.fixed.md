Stop forcing MuJoCo Warp's iterative line-search block dimension to 32 in `SolverMuJoCo`. The override worked around a CUDA registers-per-block failure that MuJoCo Warp has since capped upstream at 256 for `nv > 500`, so models above that threshold no longer run the line search at a needlessly small block size. Models at or below the threshold are unaffected, the forced value matching the upstream default there.

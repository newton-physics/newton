Add an opt-in LDL block-sparse backend to Kamino, with unit-lower L and an explicit diagonal D, MECA and RCM block ordering, CPU and CUDA solves, reusable symbolic fill, heterogeneous joint blocks, and optional dense PADMM support. Dense PADMM uses an implicit complete pattern with quadratic factor storage and factors only active rows; sparse PADMM does not support LDL. Select `dvi.bilateral_solver_type="LDL"` or `dynamics.linear_solver_type="LDL"` for dense PADMM. Kamino examples accept `--ldl` (MECA ordering) or `--ldl-ordering {meca,rcm}`. Existing LLT defaults are unchanged.

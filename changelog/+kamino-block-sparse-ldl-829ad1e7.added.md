Add the LDL block-sparse backend to Kamino, with unit-lower L and an explicit diagonal D, MECA and RCM block ordering, CPU and CUDA solves, reusable symbolic fill, heterogeneous joint blocks, and optional dense PADMM support. Dense PADMM uses an implicit complete pattern with quadratic factor storage and factors only active rows. Select either ordering in Kamino examples with `--ldl --ldl-ordering meca` or `--ldl --ldl-ordering rcm`.

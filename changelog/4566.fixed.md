Fix `add_mjcf` failing to resolve spatial tendon wrap elements (`<site>`, `<geom>` and `sidesite`) whose name contains a `-`. Wrap names were sanitized before lookup while `shape_label` keeps names as authored, so `m-origin` was looked up as `m_origin` and never matched a shape. Names are now matched exactly first and against their sanitized form as a fallback, which restores muscle-tendon paths in MyoSuite models. A tendon is only dropped when none of its wraps resolve, and a model that authors both `m-origin` and `m_origin` resolves each to its own shape.

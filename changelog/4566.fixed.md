Fix `add_mjcf` dropping every spatial tendon wrap element (`<site>`, `<geom>` and `sidesite`) whose name contains a `-`. Wrap names were sanitized before lookup while `shape_label` keeps names as authored, so a name like `m-origin` never matched and the tendon was silently discarded. Names are now matched exactly first and against their sanitized form as a fallback, so hyphenated and underscored spellings resolve to the same tendon.

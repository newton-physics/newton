Deprecate direct access to the internal `SolverStyle3D` attributes `style3d`, `linear_solver`, `pd_diags`, `pd_non_diags`, `dx`, `rhs`, `x_prev`, `x_inertia`, `static_A_diags`, `inv_A_diags`, `A_diags`, `drag_pos`, `drag_index`, and `drag_bary_coord` in Newton 1.9. Retain read-only compatibility properties for at least one full minor release cycle; reading them emits `NewtonDeprecationWarning` and returns the current internal object without copying. The properties cannot be reassigned, but returned arrays remain mutable. Solver buffers now include the selected particle and affine blocks. Use `solver.config` for runtime options, `solver.model.style3d` for material attributes, and `State` for simulation outputs; internal matrices and work buffers have no public replacement.

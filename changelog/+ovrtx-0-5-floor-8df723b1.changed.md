Require ``ovrtx`` 0.5.1.385782 or newer and ``ovstage`` 0.2.1.385922 or newer for ``ViewerRTX``, matching the pair used by Isaac Lab 3.0, and drop support for the OVRTX 0.3 attribute interface. ``ViewerRTX`` no longer sets ``OVRTX_SKIP_USD_CHECK``, which these releases do not need to run alongside ``usd-core``. To migrate, upgrade ``ovrtx`` and ``ovstage`` together, e.g. with ``pip install -U "newton[rtx]"``.

Require ``ovrtx`` 0.5.1.385782 or newer and ``ovstage`` 0.2.1.385922 or newer for ``ViewerRTX`` to fix runtime shape-opacity rendering failures with the previous minimum pair. These versions match Isaac Lab 3.0's OVRTX dependencies. Environments retaining the exact OVRTX 0.5.0.377615 / OVStage 0.2.0.377349 pins used by Isaac Sim 6.2's standalone development and examples cannot satisfy the new ViewerRTX requirements. Use a separate environment for ViewerRTX, or update and validate those environment constraints before upgrading the pair. Drop support for the OVRTX 0.3 attribute interface. ``ViewerRTX`` no longer sets ``OVRTX_SKIP_USD_CHECK``, which these releases do not need to run alongside ``usd-core``. Where environment constraints permit, upgrade ``ovrtx`` and ``ovstage`` together, e.g. with ``pip install -U "newton[rtx]"``.

Require ``ovrtx`` 0.5 or newer and ``ovstage`` 0.2 or newer for ``ViewerRTX``, matching the pairs used by Isaac Sim 6.2 and Isaac Lab 3.0, and drop support for the OVRTX 0.3 attribute interface. ``ViewerRTX`` no longer sets ``OVRTX_SKIP_USD_CHECK``, which these releases do not need to run alongside ``usd-core``. To migrate, upgrade ``ovrtx`` and ``ovstage`` together, e.g. with ``pip install -U "newton[rtx]"``.

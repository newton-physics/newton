Add declarative custom solver observables through inheritable `SolverBase.ObservableKind` string constants and nested `@dataclass(eq=False)` `Observables` containers. Declare arrays with `SolverBase.Observables.field(dtype=..., frequency=...)`; the field name supplies its kind unless an explicit `kind=` is given. Namespace subclasses reject empty or non-string entries, conflicting inherited names, and duplicate string values at class definition. Declare capabilities with `SUPPORTED_OBSERVABLES` and query `solver.supported_observables` for effective instance support. Override `observables()` for additional initialization and call `validate_observables()` before stepping.

Add experimental `Model.AttributeFrequency.CONTACT`, `CONTACT_RIGID`, and `CONTACT_SOFT` for contact-capacity-indexed arrays, with `Model.contact_max` and `Model.soft_contact_max` reporting capacities published by `CollisionPipeline`. `ArticulationView.get_attribute()` and `set_attribute()` accept observables with body, joint, or other static row frequencies.

Accept a `wp.DeterministicMode` for the `deterministic` argument of `CollisionPipeline`, `geometry.NarrowPhase` and `geometry.HydroelasticSDF`, matching the solvers. The argument now defaults to `None`, which inherits `wp.config.deterministic`, so a process-wide `wp.config.deterministic = wp.DeterministicMode.RUN_TO_RUN` now also sorts contacts; pass `deterministic=wp.DeterministicMode.NOT_GUARANTEED` to keep the previous unsorted default. `GPU_TO_GPU` is not supported: passing it raises `ValueError`, and inheriting it emits a `NewtonWarning` and runs `RUN_TO_RUN`. `CollisionPipeline.deterministic` and `NarrowPhase.deterministic` now report the `wp.DeterministicMode` in effect.

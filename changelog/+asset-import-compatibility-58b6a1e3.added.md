Add per-import compatibility options for assets tuned with Newton 1.6: `ModelBuilder.add_urdf(legacy_joint_damping=True)` restores URDF damping as per-joint drive damping while retaining the old passive-damping defaults; `ModelBuilder.add_usd(legacy_angular_velocity_units=True)` restores unconverted joint-state angular velocities; and `ModelBuilder.add_usd(legacy_springref_units=True)` restores unconverted MuJoCo spring references without changing `mjc:ref`. Keep the corrected mappings by leaving these options disabled, and use the asset migration guide to update assets and controller code.

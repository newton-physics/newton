Require every joint outside an authored articulation to belong to an articulation or close a loop on an articulated body, and remove the standalone world-root fallback from `SolverMuJoCo`. Hand-built models that add world-root joints with `add_joint_*(parent=-1, ...)` must now call `ModelBuilder.add_articulation([joint])` for those joints, or pass `finalize(skip_validation_joints=True)` when using maximal-coordinate solvers. Code that calls `add_articulation()` itself for a world joint imported by `ModelBuilder.add_usd()` must drop that call, because the joint already belongs to an articulation. World-fixed roots wrapped in single-joint articulations now convert to MuJoCo mocap bodies instead of remaining static world bodies.

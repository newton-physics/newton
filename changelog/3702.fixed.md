Add a GPU-native per-world overflow bitmask to ``SolverMuJoCo`` that surfaces contact buffer overflow without breaking CUDA graph capture. Request it with ``solver.observables({solver.ObservableFlags.OVERFLOW})``, pass the container to ``solver.step(..., observables=observables)``, and read ``observables.overflow.numpy()`` after each step. ``SolverMuJoCo.OverflowBits.CONTACT_PIPELINE`` is set when the collision pipeline drops contacts beyond ``rigid_contact_max``; ``SolverMuJoCo.OverflowBits.SOLVER_NCONMAX`` is set when contacts exceed the solver's ``nconmax`` capacity. Bits 0–15 carry ``mujoco-warp``'s own ``OverflowType`` flags (``NEFC``, ``NJMAX_NNZ``, etc.). The bitmask resets each step so it always reflects the current step only. The request is rejected with ``use_mujoco_cpu=True``.

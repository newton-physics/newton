Add ``state.mujoco.overflow`` — a GPU-native per-world bitmask that surfaces contact buffer overflow from ``SolverMuJoCo`` without breaking CUDA graph capture. Request it via ``builder.request_state_attributes("mujoco:overflow")`` and read ``state.mujoco.overflow.numpy()`` after each step. Bit 16 (``OVERFLOW_CONTACT_PIPELINE``) is set when the collision pipeline drops contacts beyond ``rigid_contact_max``; bit 17 (``OVERFLOW_SOLVER_NCONMAX``) is set when contacts exceed the solver's ``nconmax`` capacity. Bits 0–15 carry ``mujoco-warp``'s own ``OverflowType`` flags (``NEFC``, ``NJMAX_NNZ``, etc.). The bitmask resets each step so it always reflects the current step only.

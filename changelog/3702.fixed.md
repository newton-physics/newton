Raise a `RuntimeError` (or emit a `UserWarning` in the default non-strict mode) when Newton's contact buffer exceeds `SolverMuJoCo`'s `nconmax` capacity, rather than silently discarding contacts and producing NaN results. A new `strict_capacity` constructor argument controls the behaviour: when `False` (default) a `UserWarning` is emitted and simulation continues; when `True` a `RuntimeError` is raised immediately on the capacity mismatch (no GPU sync) and again after each step if runtime contacts or solver constraints overflowed (requires a GPU sync). The existing device-side `wp.printf` message in the contact conversion kernel is preserved for users without Python-level warning capture.

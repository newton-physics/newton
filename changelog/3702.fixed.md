Add a GPU-native per-world overflow bitmask to ``SolverMuJoCo`` that surfaces contact buffer overflow without breaking CUDA graph capture. Request it with ``solver.observables({solver.ObservableKind.OVERFLOW})``, pass the container to ``solver.step(..., observables=observables)``, and read ``observables.overflow.numpy()`` after each step. ``SolverMuJoCo.OverflowBits.CONTACT_PIPELINE`` is set when the collision pipeline drops contacts beyond ``rigid_contact_max``; ``SolverMuJoCo.OverflowBits.SOLVER_NCONMAX`` is set when contacts exceed the solver's ``nconmax`` capacity. Bits 0–15 carry ``mujoco_warp.OverflowType`` flags (``NEFC``, ``NJMAX_NNZ``, etc.). Each requested step overwrites the bitmask; steps without the observable leave it unchanged. Newton flags describe shared contact buffers and are repeated in every world mask when the global count exceeds capacity. The request is rejected with ``use_mujoco_cpu=True``. Reject MuJoCo Warp backends whose declared overflow flags extend beyond bits 0–15 to prevent collisions with Newton flags.

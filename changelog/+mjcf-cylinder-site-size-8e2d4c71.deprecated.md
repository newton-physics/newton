Deprecate the `mujoco:site_size_is_display` shape attribute registered by `SolverMuJoCo`. The MJCF importer no longer populates it, and it no longer has any effect on `ModelBuilder` validation, shape bounds, or viewer rendering. Remove code that sets or reads it; set `scale[2]` of a cylinder site to `0.0` if it should not have a barrel radius.

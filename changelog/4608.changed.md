Store `Model.mesh_edge_centers` and `Model.mesh_edge_halves` in unscaled mesh coordinates, with one edge range shared by all shapes that use the same mesh, and apply the current shape scale when `NarrowPhase` reads them. Code that passes the `Model` arrays to `NarrowPhase.launch()` or `NarrowPhase.launch_custom_write()` needs no change. Code that packs these arrays itself must use unscaled mesh-vertex coordinates, with each center's `w` set to the length of the unscaled half-vector, or pass `None` to read edges from the mesh during collision.

Store packed collision-edge centers and half-vectors in unscaled mesh coordinates, with one edge range shared by all shapes that use the same mesh, and apply the current shape scale when `NarrowPhase` reads them. Custom callers of `NarrowPhase.launch()` or `NarrowPhase.launch_custom_write()` must pack caller-owned arrays in unscaled mesh-vertex coordinates, with each center's `w` set to the length of the unscaled half-vector, or omit centers and half-vectors to read edge endpoints from the mesh using caller-owned edge indices and per-shape ranges. Omitting the edge indices or ranges disables mesh edge contacts. The `Model.mesh_edge_*` and `Model.shape_edge_range` aliases are deprecated; use `CollisionPipeline` for model collision detection.

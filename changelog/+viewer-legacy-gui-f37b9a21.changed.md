Make the docked inspection workspace the default ViewerGL GUI. Its panels cost about 1–2 ms more CPU time per interactive frame than the legacy sidebar, so pass `ViewerGL(legacy_gui=True)` where frame rate matters more than inspection. Headless rendering is unaffected. In a visible window, `get_frame()` returns the scene inside the docked viewport, surrounded by panel background; set `viewer.show_ui = False` or pass `legacy_gui=True` to capture the scene at full window size.

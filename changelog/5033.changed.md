Change `SensorCamera.RenderConfig.gaussians_min_transmittance` from the transmittance below which Gaussian splats count as a hit to the transmittance at which a ray stops blending splats, and lower its default from 0.49 to 1e-4 to match the 3D Gaussian splatting rasterizer. Code that set it to choose which splats count as a surface can drop the setting, because the depth output now reports the splats where their accumulated opacity exceeds one half. Raise the value only to trade accuracy for speed. `SensorCamera.GaussianRenderMode.FAST`, the default, still blends only the nearest `gaussians_max_num_hits` splats per ray, and the light they let through now shows the shape or clear color behind them. Use `SensorCamera.GaussianRenderMode.QUALITY` to keep blending the splats past that limit.

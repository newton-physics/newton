Keep the neighbor body of each cross-solver joint as a `BodyFlags.PROXY` joint proxy when `SolverCoupledADMM.Config.joint_proximal_bodies` is set. The proxy follows the owned body's ADMM iterate with the joint's `rho * W**2` inertia, so it changes convergence but not the converged answer, and keeps high `rho` stable. `joint_proximal_mass_scale` now scales this inertia; reset tuned values to `1.0` and retune.

Require `mujoco-core~=4.0.1` and `mujoco-warp~=4.0.1` (previously `mujoco~=3.17.0` and `mujoco-warp~=3.17.0`). MuJoCo 4.0 moves its bindings from `mujoco` to `mujoco-core`, so in an existing pip environment run `pip uninstall -y mujoco` before `pip install --upgrade "newton[sim]"`; otherwise the old `mujoco` files break the installation. MuJoCo 4.0 also changes `SolverMuJoCo` results for spatial tendons wrapping around a `sidesite`, `integrator="rk4"` with ball or free joints, and implicit integration of actuators saturated by `actuatorfrcrange`; see the [MuJoCo 4.0 changelog](https://mujoco.readthedocs.io/en/4.0.0/changelog.html) for migration notes.

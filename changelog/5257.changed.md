Sort deterministic contacts by a separate `(shape_a, shape_b)` pair key in a second stable radix pass when shape indices and the contact sub-key don't fit in one 63-bit key, so `CollisionPipeline` models with meshes, heightfields, hydroelastic shapes or primitive shapes with an SDF support `deterministic=True` and contact matching above `2**20` shapes instead of raising `ValueError`. A standalone deterministic `NarrowPhase` gets the same support only when it is constructed with `shape_aabb_lower` and `shape_aabb_upper`; without them it still raises `ValueError` at launch above `2**20` shapes, so pass both arrays to use it with larger models.

Add a mechanism for actuator drives to declare arrays the application must supply beyond the standard state and targets. A drive lists them in `DriveBase.custom_inputs` as `(source, attribute)` pairs naming which `Actuator.step()` argument carries each array; `Actuator` reads them from `sim_state` or `sim_control` and passes them to the drive's `compute()` and `prepare_implicit()`. `Actuator.sim_state()` and `Actuator.sim_control()` return empty containers exposing exactly the fields an actuator reads.

Deprecate `ModelBuilder.add_muscle()` and the legacy muscle data in `ModelBuilder.muscle_*`, `Model.muscle_*`, `Model.muscle_count`, and `Control.muscle_activations`. Only `SolverSemiImplicit` evaluated these muscles, and it ignored the muscle parameters. Use `SolverMuJoCo` muscle actuators instead: import MJCF `<muscle>` actuators, or build them in code with `newton.solvers.mujoco.add_tendon_spatial()` through sites on the waypoint bodies and `add_actuator_general(builder, ActuatorTarget.tendon(tendon), dyntype="muscle", gaintype="muscle", biastype="muscle")` with explicit muscle `dynprm`, `gainprm`, and `biasprm` values; the `add_muscle()` documentation lists MuJoCo's defaults. MJCF muscle import is unaffected.

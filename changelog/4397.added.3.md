Add per-actuator arrays: `ModelBuilder.add_actuator()` returns the index of the actuator, the model stores the DOF of each actuator as `actuation.actuator_dof`, and actuators built by `ModelBuilder` write their effort before clamping to `control.actuator_computed_effort` and the effort they apply to the simulation to `control.actuator_applied_effort`. Drives read per-actuator inputs by declaring them in `DriveBase.custom_inputs` with the frequency `"actuation:actuator"`, and `Actuator` takes `actuator_indices`, with which `control_computed_output_attr` and the new `control_applied_output_attr` are written per actuator.

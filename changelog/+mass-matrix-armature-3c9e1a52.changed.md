Fix `newton.eval_mass_matrix()` and `ArticulationView.eval_mass_matrix()` to include `Model.joint_armature` on the diagonal by default. The matrix now matches the joint-space inertia that `SolverMuJoCo`, `SolverFeatherstone` and `SolverKamino` integrate. `eval_inverse_dynamics_passive()`, `ArticulationView.eval_inverse_dynamics_passive()`, and the joint-impedance and operational-space controllers also use the matrix with armature. To migrate, remove any code that adds `joint_armature` to the result by hand, or pass `include_armature=False` for now.

Remove the unused `rigid_body_linear_damping` / `rigid_body_angular_damping` entries from `SchemaResolverPhysx`. No importer code read these keys, so authored `physxRigidBody:linearDamping` / `physxRigidBody:angularDamping` values were never applied by them. `SolverSteel.register_custom_attributes()` still imports both attributes by USD name, and the raw values remain available in `schema_attrs["physx"]` when the PhysX resolver is used.

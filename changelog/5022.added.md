Honor USD `newton:maxSolverIterations` in `SolverVBD` when `iterations` is omitted or `None`, preserving explicit overrides and the default of `10` for an absent setting or the `-1` schema fallback. Scene values must be positive or `-1`; zero is rejected because the particle output is not valid without a solve iteration. VBD uses a fixed iteration count, so existing assets with large authored values now perform more work per step. Pass `iterations=10` explicitly to retain the previous default workload.

Fix hollow (`is_solid=False`) mesh and convex-mesh shapes reusing the mesh's cached 1 mm shell inertia, which ignored the requested shell thickness (`ShapeConfig.margin`) and scaled the shell with the mesh volume. Hollow mesh shapes now validate their shell thickness the way hollow primitives do: the default `margin=0.0` gives zero mass and emits a warning (set `ShapeConfig.margin` to the desired shell thickness to keep them dynamic), and a negative or non-finite thickness raises `ValueError`. This includes USD imports with `legacy_margin_gap=True` where `mjc:margin < mjc:gap` produces a negative margin on a shell-inertia mesh collider, which previously imported. Per-vertex thickness must have one value per mesh vertex.

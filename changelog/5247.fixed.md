Fix hollow (`is_solid=False`) mesh and convex-mesh shapes reusing the mesh's cached 1 mm shell inertia, which ignored the requested shell thickness (`ShapeConfig.margin`) and scaled the shell with the mesh volume. Hollow mesh shapes now have zero mass with the default `margin=0.0` and emit a warning, as hollow primitives do; set `ShapeConfig.margin` to the desired shell thickness to keep them dynamic.

Compact experimental coupled-solver entry views when worlds select different bodies, joints, or shapes; previously such entries fell back to the full model layout and saw the other entries' rows as disabled. Code that relied on the full layout for such entries should read the view's own counts and world-start arrays, or use the entry's local-to-global maps. Solvers that require identical worlds, such as `SolverMuJoCo`, need the same selection in every world, and `SolverCoupled` names the entry when such a solver rejects its view.

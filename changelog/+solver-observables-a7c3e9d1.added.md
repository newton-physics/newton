Add experimental, solver-owned `SolverBase.Observables` containers for optional solver diagnostics: rigid-body accelerations, parent-joint wrenches, contact forces, and MuJoCo actuator forces (`SolverMuJoCo.ObservableKind.QFRC_ACTUATOR`). Allocate reusable arrays with `solver.observables(kinds)` from composable `SolverObservableKind` sets, populate them with `solver.step(..., observables=observables)`, and consume them with `SensorIMU.update()`, `SensorContact.update()`, and `ViewerBase.log_contacts()` through `observables=`. Use `SolverBase.Observables.select(kinds)` to create reusable subsets that share the preallocated arrays, for example to sample diagnostics only on selected substeps. Custom solvers declare typed arrays with `SolverBase.Observables.field(kind=..., dtype=..., frequency=...)` on inherited `@dataclass(eq=False)` containers, defined as each solver's nested `Observables` class with `SUPPORTED_OBSERVABLE_KINDS`. Generic allocation replaces per-field frequency maps and handwritten allocation code. Override `observables()` for solver-specific initialization and call `validate_observables()` before stepping; shared allocation bookkeeping remains internal.

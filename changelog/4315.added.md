Add `SolverXPBD(joint_drive_mode=...)`: `"pd"` solves position/velocity drives so that `joint_target_ke`/`joint_target_kd` are the stiffness and damping at any iteration count, bounded by `Model.joint_effort_limit` (start-of-step spring with exact static equilibria, backward-Euler damper row); `"implicit"` uses accumulated-impulse implicit PD rows; the default `"compliance"` keeps the former drive, whose effective stiffness grows with the iteration count. The applied drive force per DOF is available as `SolverXPBD.joint_drive_force`.

Require `coacd>=1.0.14` in the `importers` extra so that CoACD convex decompositions in `ModelBuilder.approximate_meshes()` repeat across runs for a fixed seed; earlier releases collect parallel results in thread-completion order. CoACD 1.0.13 changed its hull-merge cost, so decompositions with merging enabled, such as USD `convexDecomposition` colliders, can differ slightly from those of older releases. Upgrade existing environments with `pip install "coacd>=1.0.14"`.

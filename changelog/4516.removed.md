Remove runtime `Model.mujoco.dof_passive_stiffness` and `Model.mujoco.dof_springref` arrays without a runtime deprecation period: absolute, DOF-indexed aliases cannot directly represent the new relative, coordinate-indexed rest values. Legacy builder inputs are converted once during finalization. Use `Model.joint_stiffness` and coordinate-indexed `Model.joint_rest_q` (`springref - ref`) for runtime reads and writes, then notify the solver with `ModelFlags.JOINT_DOF_PROPERTIES`. Later `dof_ref` edits leave the Newton rest coordinate fixed and export `qpos_spring = joint_rest_q + ref`, replacing the legacy behavior that kept the absolute MuJoCo spring reference fixed.

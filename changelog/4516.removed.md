Remove runtime `Model.mujoco.dof_passive_stiffness` and `Model.mujoco.dof_springref` without a runtime deprecation period, making the core fields the sole runtime spring API. Stiffness is a direct rename to DOF-indexed `Model.joint_stiffness`; the spring reference additionally changes from absolute, DOF-indexed MuJoCo coordinates to relative, coordinate-indexed `Model.joint_rest_q` (`springref - ref`), so it cannot be a direct array alias. Legacy builder inputs remain accepted and are deprecated separately, with conversion during finalization. Migrate runtime reads and writes to the core arrays, then notify the solver with `ModelFlags.JOINT_DOF_PROPERTIES`. Later `dof_ref` edits leave the Newton rest coordinate fixed and export `qpos_spring = joint_rest_q + ref`, replacing the legacy behavior that kept the absolute MuJoCo spring reference fixed.

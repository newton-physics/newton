Add solver-owned collision pipelines: `SolverBase` accepts `pipeline=...` with per-slot detection scheduling (`collision_frequency`, `collision_frequency_type`, runtime-changeable via `SolverBase.set_collision_frequency`) and a read-only `SolverBase.contacts` buffer; `SolverVBD` adopts them, and soft self-contact results land in `Contacts.soft_self_contact_data` via `CollisionPipeline.init_soft_self_contact()`, `collide(soft_self_contact=True)`, and `refit_soft_self_contact_bvh()`. Detection ranges can be updated at runtime with `CollisionPipeline.set_collision_detection_range()`. `SolverVBD` also implements the experimental rigid `ITERATIONS` mode: mid-solve re-detection at the current iterate poses, carrying in-flight contact state through the matched warm-start restore (cold restart when `rigid_contact_history`/contact matching are off).

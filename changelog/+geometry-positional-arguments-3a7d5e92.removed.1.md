Remove `Gaussian.warp_data` and `Gaussian.warp_bvh`, deprecated in Newton 1.6; use the `Gaussian.Data` object returned by `Gaussian.finalize()` and `Gaussian.bvh` instead. Two uses have no replacement: assigning a custom BVH, since `Gaussian.bvh` is read-only and `Gaussian.finalize()` always builds the BVH, and reading the data that `ModelBuilder.finalize()` creates for a Gaussian in a model, which has no Python accessor.

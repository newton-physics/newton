Apply MJCF `<compiler settotalmass>` in `ModelBuilder.add_mjcf()`, which was previously ignored so imported models kept their authored masses instead of being rescaled to the requested total. Mass and inertia now take the same linear factor, jointless bodies count toward the total as they do in MuJoCo, and a non-positive value remains a no-op. Only bodies created by the import are rescaled, leaving any bodies the destination builder already held untouched.

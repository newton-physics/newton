Speed up `SolverMuJoCo` steps that use MuJoCo Warp's Newton solver by skipping the unconstrained acceleration `qacc_smooth` and the factorization of the inertia matrix; the solver starts from the previous step's acceleration instead. Pass the new `run_qacc_smooth=True` to keep both, which code that reads `mjw_data.qacc_smooth` or calls `mujoco_warp.solve_m` after a step requires, such as the solver-backed `JointSpaceResponse.refresh_from_solve`.

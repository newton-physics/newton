Skip the unconstrained acceleration `qacc_smooth` and the factorization of the inertia matrix in `SolverMuJoCo` steps where MuJoCo Warp's Newton solver does not need them, which makes these steps faster; the solver starts from the previous step's acceleration instead. Code that calls `mujoco_warp.solve_m` after a step, such as the solver-backed `JointSpaceResponse.refresh_from_solve`, must call `mujoco_warp.factor_m` first; code that reads `mjw_data.qacc_smooth` must pass the new `run_qacc_smooth=True`, which keeps both.

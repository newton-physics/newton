Deprecate the `SolverVBD` arguments `rigid_avbd_alpha`, `rigid_avbd_joint_alpha`, and `rigid_avbd_contact_alpha`; explicit values are still applied and emit a `NewtonDeprecationWarning`. Omit them: the default applies no C0 stabilization to joints and body-body contacts. Scenes that used alpha to soften the correction of initial overlaps or joint gaps should start from a consistent configuration instead.

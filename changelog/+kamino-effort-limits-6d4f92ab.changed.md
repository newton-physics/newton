Change the default of `newton.solvers.SolverKamino.Config.dvi.use_schur_complement` from `False` to `None`, which selects Schur elimination automatically when the model contains bounded implicit-PD drives and alternating solves otherwise. Alternating solves converged very slowly for bounded drives whose joint inertia dwarfs the body inertia. Set `dvi.use_schur_complement=False` to keep the previous behavior.

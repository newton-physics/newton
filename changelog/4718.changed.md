Compute the `SolverImplicitMPM` material extrema that select solver code paths (minimum Young's modulus, maximum hardening, viscosity, dilatancy) over all non-collider particles, active or inactive, proxy or not, so changing `ParticleFlags.ACTIVE` or `ParticleFlags.PROXY` at runtime never changes the code paths. Inactive and proxy particles with viscosity, dilatancy, hardening or compliance now enable those paths up front; leave such particles at the default `mpm:*` attributes to avoid that.

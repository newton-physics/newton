Compute the `SolverImplicitMPM` material extrema that select solver code paths (minimum Young's modulus, maximum hardening, viscosity, dilatancy) over all particles that can carry material, active or not, so changing particle activity never changes the code paths. Inactive particles with viscosity, dilatancy, hardening or compliance now enable those paths up front; leave unused particles at the default `mpm:*` attributes to avoid that.

Add experimental OptiX ray tracing for `SensorCamera` and `intersect_ray` with `backend="optix"`, installed with the `optix` extra. `Model.bvh_build_shapes()` and `Model.bvh_refit_shapes()` take a `backend` argument and build and refit the OptiX shape acceleration with `backend="optix"`. Build it once and refit it each frame, since the OptiX build is several times slower than the Warp BVH build. Each world's shapes must stay within the region set at build time (`optix_extent`); OptiX hides shapes that leave it and sets `Model.optix_shapes.out_of_cell`.

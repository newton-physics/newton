Add the experimental `friction_mode` option of `newton.solvers.SolverFeatherPGS` (matrix-free solve only), which selects the Coulomb friction update: `"current"` (the default), `"bisection"` and `"bisection_desaxce"`, which bisect each contact's normal impulse with the tangent problem re-solved at every probe (the latter with the de Saxce maximum-dissipation bias on free-body contacts), and `"coulomb_newton"`, which solves each free-body contact's Coulomb cone with a bracketed Newton iteration. The non-default modes use point friction; the split solve raises `NotImplementedError` for them.

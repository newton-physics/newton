Add experimental `SensorCamera.set_ambient_light()` to set the hemispheric ambient sky and ground colors, and an experimental `color` argument on `SensorCamera.create_default_light()`. Both are runtime inputs, so changing them does not recompile the render kernel. Default output is unchanged. `SensorCamera` scene lighting, including how `create_default_light()` combines with model lights, is now experimental in anticipation of rendering lights imported from USD and MJCF.

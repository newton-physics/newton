Add shape groups and shape filters to select the shapes that ray casts and cameras see. Assign shapes to named groups with `ModelBuilder.ShapeConfig.groups` or `ModelBuilder.add_shape_group()`, describe shape subsets with `newton.ShapeFilter` (flags, groups, and label patterns with exclusions), and register them with `ModelBuilder.add_shape_filter()`. Pass the returned id as `shape_filter` to `newton.intersect_ray()` and `SensorCamera`; `SensorContact` also accepts a `ShapeFilter` for `sensing_shapes` and `counterpart_shapes`. The shape BVH is partitioned by the registered filters, so each query traverses only the shapes it selects. Assets author groups with the USD attribute `newton:shapeGroups`, which shapes inherit from ancestor prims, and with MJCF geom `group` through `ModelBuilder.add_mjcf(..., geom_groups_as_shape_groups=True)`.

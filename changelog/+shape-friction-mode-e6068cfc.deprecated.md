Deprecate the `mujoco:condim` custom attribute of `SolverMuJoCo`. Importers set `ModelBuilder.ShapeConfig.friction_mode` instead; values other than the default 3 set in code are folded into the friction mode at `ModelBuilder.finalize()`, which raises `ValueError` if a shape also sets a different non-default mode, and `Model.mujoco.condim` becomes a copy of `Model.shape_material_friction_mode` whose edits are applied when it is next read or a `SolverMuJoCo` is constructed. Both emit a deprecation warning, and `mujoco:condim` is no longer accepted on body variant shapes. Map `condim` 1, 3, 4, and 6 to `ShapeFrictionMode.NONE`, `SLIDING`, `TORSIONAL`, and `ROLLING`.

Deprecate the `mujoco:condim` custom attribute of `SolverMuJoCo`. Importers set `ModelBuilder.ShapeConfig.friction_mode` instead; per-shape values set in code override the friction mode at `ModelBuilder.finalize()`, a changed default applies to shapes left at `SLIDING`, and `Model.mujoco.condim` becomes a copy of `Model.shape_material_friction_mode` whose edits are applied when it is next read or a `SolverMuJoCo` is constructed. Each emits a deprecation warning, and `mujoco:condim` is no longer accepted on body variant shapes. Map `condim` 1, 3, 4, and 6 to `ShapeFrictionMode.NONE`, `SLIDING`, `SLIDING_TORSIONAL`, and `SLIDING_TORSIONAL_ROLLING`.

Deprecate the `mujoco:condim` custom attribute of `SolverMuJoCo`. Importers set `ModelBuilder.ShapeConfig.friction_mode` instead; values set in code are folded into the friction mode at `ModelBuilder.finalize()`, which raises `ValueError` if a shape also sets a different non-default mode, and `Model.mujoco.condim` becomes a read-only copy derived from `Model.shape_material_friction_mode`. Both emit a deprecation warning. Map `condim` 1, 3, 4, and 6 to `ShapeFrictionMode.NONE`, `SLIDING`, `TORSIONAL`, and `ROLLING`.

Deprecate `SolverMuJoCo(update_data_interval=...)` and the `SolverMuJoCo.update_data_interval` attribute in Newton 1.8; MuJoCo data will always be synchronized from the input state on every step. Passing the argument, including `1`, and reading or assigning the attribute emit a `NewtonDeprecationWarning`. Remove its use, and pass the latest state as `state_in` to every `step()` call.

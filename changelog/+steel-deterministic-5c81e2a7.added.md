Add `SolverSteel(deterministic=wp.DeterministicMode.RUN_TO_RUN)`, which reserves constraint rows in a fixed per-world order (joint rows in articulation order, contact rows in contact-buffer order) instead of through atomic counters, and sums split-mode right-hand sides in a fixed order. With identically ordered contacts, for example from `CollisionPipeline(deterministic=True)`, repeated runs are bitwise identical on the same GPU model, driver and Warp build, eagerly and under CUDA graph replay. The default (`None`) inherits `wp.config.deterministic`, which is off unless set. The mode requires `articulated_contact_response="immediate"` and rejects an explicit `GPU_TO_GPU`; an inherited mode the solver cannot provide falls back to the strongest supported one with a `NewtonWarning`.

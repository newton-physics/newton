Add `ModelBuilder.ShapeConfig.mu_static` and `Model.shape_material_mu_static` for a separate static (break-away) friction coefficient, preserve USD `physics:staticFriction` on import, and pass it to `SolverKamino` material tables. An unset value resolves to `mu` (a single coefficient) and a value below `mu` is rejected; an MJCF geom `friction` sets a single coefficient. No built-in solver distinguishes the two in its contact model yet, so existing models behave as before.

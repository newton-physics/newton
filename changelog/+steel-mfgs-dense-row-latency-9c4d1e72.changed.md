Shorten the per-row latency of `SolverSteel`'s fused matrix-free Gauss-Seidel sweep, which runs each world's dense rows as one serial chain: streamed row metadata is loaded with the next row's prefetched Jacobian, each contact torsion row issues its own loads before walking its members, and, when a shared-memory estimate admits all worlds, each launch sets up its friction pairs' 2x2 operators once and keeps a compact shared copy of row types and parents.

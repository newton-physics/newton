Change actuator index arrays to name one or more joints per actuator: `Actuator.indices`, `pos_indices` and `effort_indices` are now 2-D with shape `(joints, N)`; a 1-D array passed to `Actuator` is the single-joint case. `ModelBuilder.add_actuator()` accepts a sequence for `index` and `pos_index`; several joints require a transmission other than `TransmissionDirect`. Code that reads `Actuator.indices` as one DOF per actuator should read `actuator.indices[0]`, and `ModelBuilder.ActuatorEntry.indices` and `pos_indices` now hold one tuple of DOFs per actuator, so read `entry.indices[i][0]`. Clamps and motors now read the actuator velocity from the transmission, so an input processor that replaces `velocities` no longer changes what they read. `ArticulationView.get_actuator_parameter()` and `set_actuator_parameter()` map each actuator to its first DOF only.

Change actuator index arrays to name one or more joints per actuator: `Actuator.indices`, `pos_indices` and `effort_indices` are now 2-D with shape `(joints, N)`; a 1-D array passed to `Actuator` is the single-joint case. `ModelBuilder.add_actuator()` accepts a sequence for `index` and `pos_index`, and takes the new `effort_index`. Several joints require a transmission. Code that reads `Actuator.indices` as one DOF per actuator should read `actuator.indices[0]`.

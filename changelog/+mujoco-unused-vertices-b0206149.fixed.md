Fix `SolverMuJoCo` exporting mesh vertices that no triangle uses. An unused vertex off a flat mesh made the mesh look solid. MuJoCo then collided with a shape that reached up to that vertex. The export now drops unused vertices, so such a mesh is treated like any other flat mesh. MuJoCo contacts do not support flat meshes, so they now report the usual planar mesh collider error instead of colliding with the wrong shape.

Fix mesh contacts on heightfield, mesh, and SDF shapes ignoring `Model.shape_scale` changes made after `ModelBuilder.finalize()` or after `CollisionPipeline` construction. Precomputed collision edges now apply the current shape scale. Texture SDFs built without a baked scale follow scale changes when the pipeline is constructed with `dynamic_shape_scale=True`; without it, when the pipeline compiled unit-scale SDF queries for such a shape, rescaling it prints a device warning and makes a later eager `CollisionPipeline.collide()` call (outside graph capture) raise a `RuntimeError` instead of being ignored.

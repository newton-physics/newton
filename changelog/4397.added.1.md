Add actuator motors, which turn the duty command computed by the drive into motor effort: `newton.actuators.MotorDC`, a DC motor driven by average terminal voltage as in BAM (Better Actuator Models). The actuator bounds duty to `[-1, 1]` and converts it using actual supply voltage. Add `ClampingCurrentDuty`, which attempts current limiting using supplied or nominal voltage before bounding duty. Pass motors through `Actuator(motor=...)` or `ModelBuilder.add_actuator(motor=...)`; USD authors them with duty-configured drive schemas, `NewtonCurrentDutyClampingAPI` and `NewtonDCMotorAPI`. See the actuators concept documentation (`docs/concepts/actuators.rst`).

Add `physx_missing_inertia_fallback` to `ModelBuilder.add_usd()`. When enabled, every body with an authored positive mass but no authored inertia gets the inertia of a solid sphere of radius 0.1 m (in stage units) with that mass. This explicit override matches OpenUSD's observed small-sphere formula; it does not detect PhysX fallback conditions and also replaces usable collider-derived inertia. It is off by default, so default import behavior is unchanged.

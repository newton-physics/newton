Remove the `JointType.CABLE` alias, deprecated in 1.6; use `JointType.ROD` instead. Its integer value remains `7`, and its canonical enum name is now `"ROD"`, so code that stores enum names must use `"ROD"`. Remove the `ModelBuilder.add_joint_cable()` alias, deprecated in 1.6; use `ModelBuilder.add_joint_rod()` instead. Remove `ModelBuilder.add_rod(positions=...)`, `ModelBuilder.add_rod_graph()`, `newton.utils.CableStiffness`, and the four deprecated `create_*` cable helpers. Construct `newton.Rod(points, ...)` (with `edges=...` for a graph), supply geometry and material properties on the Rod, and assemble it with `ModelBuilder.add_rod(rod=...)`. Use `Rod.create_straight()` for straight geometry and `Rod.quaternions` for segment frames; call `Rod.compute_frames(twist_total=...)` first for nonzero twist.

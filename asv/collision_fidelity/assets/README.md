# Collision-fidelity runtime inputs

`manifest.json` identifies the runtime assets and their licenses. The 16
procedural cloth and solid meshes are generated by `../assets.py`, under
Apache-2.0. Their recorded coarse mesh hashes identify an archived generation;
they are provenance, not cross-platform acceptance limits. Delaunay triangle
ordering and diagonal choices can vary across platforms. Tests instead check
connected, consistently oriented surfaces, garment openings and welded seams,
solid volume validity, dimensions and usable landmarks. These checks preserve
the test mechanism; they do not promise identical trajectories.
Dimensions use a 1% relative tolerance to check approximate input scale, not
to set a physical acceptance limit.
Scene-specific refinement remains in the scene builders. These meshes are
synthetic benchmark shapes, not measured garment or material models.

The complete native Style3D jacket is included as `cached_jacket_native.npz`.
It retains 33,703 vertices and 66,930 triangles. Its source revision, transform,
mesh hash and BSD-3-Clause notice are in the adjacent metadata and
`STYLE3D-LICENSE.txt`. It is not simplified at load time.

Franka, Allegro and H1 robot assets are downloaded lazily through
`newton.utils.download_asset` at the revision pinned in `../asset_paths.py`.
The original license files remain in each downloaded folder. `NEWTON_CACHE_PATH`
selects the external asset cache. Catalog discovery downloads nothing. The
rubber-duck asset remains listed for the unsupported two-solver case.

`h1/` contains four versioned initialization fixtures. They contain public
State/Control values, rest geometry and prescribed hand keyframes. They do
not contain solver histories or reference rollout outputs. The original
preparation and command hashes are recorded in each JSON file. The jacket
starts from its selected corrected open-hand pose. The towel preserves its
selected closed-thumb correction; the wrist path and release commands are
unchanged. Sheet and gusset inputs retain their original saved starts. The
gusset begins in prepared body-rim contact; no acquisition is claimed.
The source hand geometry retains Unitree's BSD-3-Clause license. The jacket
coordinates also retain the bundled Style3D notice. Generated state and command
data use the benchmark's Apache-2.0 license.

Gallery previews, superseded meshes and old results are not runtime inputs.
They remain preserved in the original experiment archive at
`https://github.com/AnkaChan/newton/tree/50045b89b546a9a791812fa8d22413e04be4f416/experiments/collision_benchmark`.
No benchmark writes generated files into this directory.

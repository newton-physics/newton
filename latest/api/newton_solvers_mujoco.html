newton.solvers.mujoco#

Programmatic model-authoring helpers for SolverMuJoCo.

The module-level helpers create MuJoCo-specific actuators, tendons, contact pairs, and equality constraints on a ModelBuilder without exposing custom-frequency storage details. Use SolverMuJoCo as the canonical public solver class.

Example:

from newton.solvers import mujoco

actuator = mujoco.add_actuator_position(
    builder,
    target=mujoco.ActuatorTarget.joint(joint),
    kp=10.0,
    kv=2.0,
)

Note

This page documents helper functions exposed through the newton.solvers.mujoco attribute. Because newton.solvers is a module rather than a package, use from newton.solvers import mujoco instead of import newton.solvers.mujoco.

class newton.solvers.mujoco.ActuatorTarget(kind, index, secondary_index=-1, dof=None)[source]#

A typed MuJoCo actuator transmission target.

Construct targets with joint(), joint_dof(), tendon(), site(), body(), or slider_crank(). The authoring helper resolves the target to MuJoCo’s heterogeneous trnid representation.

Targets must belong to the builder’s current world or the global world (-1). For ball and free joints, the native MuJoCo transmission requires an explicit three- or six-component gear, respectively, and does not select a Newton DOF. Ball gears express torque in the child body frame; free gears combine world-frame force at the body origin with child-frame torque. Use joint_f to apply forces in Newton’s DOF convention.

newton.solvers.mujoco.add_actuator_dcmotor(builder, target, *, motorconst=(0.0,), resistance=0.0, nominal=(0.0,), saturation=(0.0,), inductance=(0.0,), cogging=(0.0,), controller=(0.0,), thermal=(0.0,), lugre=(0.0,), input='voltage', gear=(1.0,), damping=(0.0,), armature=0.0, ctrlrange=None, ctrllimited='auto', cranklength=None, ctrl=0.0, custom_attributes=None)[source]#

Add a native DC motor controlled through control.mujoco.ctrl.

Requires the optional mujoco package (included in newton[sim]), but not MuJoCo-Warp. Native MuJoCo resolves the electrical and controller parameters; these are construction-time properties, not runtime-editable general-actuator gains. No model is compiled by this helper. Parameter vectors are zero-padded before native default inference, as in MJCF. Force limits are derived from saturation, not separate forcerange/forcelimited options, matching the native shortcut.

Parameter ordering and inference follow the MuJoCo DC-motor reference.

Parameters:

  • builder (ModelBuilder) – Model builder receiving the actuator.

  • target (ActuatorTarget) – Typed actuator transmission target.

  • motorconst (Sequence[float]) – Torque constant [N·m/A] and back-EMF constant [V·s/rad].

  • resistance (float) – Winding resistance [ohm]. Supply sufficient nonzero motorconst, resistance, or nominal values for native inference.

  • nominal (Sequence[float]) – Voltage [V], stall torque [N·m], and no-load speed [rad/s].

  • saturation (Sequence[float]) – Torque [N·m], current [A], and current-rate [A/s] limits.

  • inductance (Sequence[float]) – Winding inductance [H] and electrical time constant [s].

  • cogging (Sequence[float]) – Torque amplitude [N·m], pole count, and phase [rad].

  • controller (Sequence[float]) – kp, ki, kd, slew limit, integral limit, and voltage limit; see the linked native reference for input-dependent units.

  • thermal (Sequence[float]) – Thermal resistance [K/W], capacitance [J/K], time constant [s], resistance temperature coefficient [1/K], reference and ambient temperatures [degrees Celsius].

  • lugre (Sequence[float]) – Bristle stiffness [N·m/rad], damping [N·m·s/rad], Coulomb and static friction torques [N·m], and Stribeck speed [rad/s].

  • input (str | int) – Single control input: voltage (8), pos (1), or vel (2). Accepts a native keyword or its integer control signature. Other signatures raise NotImplementedError.

  • gear (Sequence[float]) – Native transmission gear, padded to six values. Ball/free joints require explicit native gear as described in ActuatorTarget. With nonzero damping on the Warp backend, gear must match across replicated worlds and cannot change after solver construction.

  • damping (Sequence[float]) – Coefficients of -d0*v - d1*abs(v)*v - d2*v**3 in actuator velocity v. Coefficient dn has units [N·m·(s/rad)^(n+1)] for angular transmissions or [N·(s/m)^(n+1)] for linear ones.

  • armature (float) – Passive rotor inertia [kg·m² or kg for linear transmissions]. Currently supported only by native MuJoCo.

  • ctrlrange (Sequence[float] | None) – Optional two-value control range: voltage [V], position [m or rad], or velocity [m/s or rad/s], in actuator coordinates.

  • ctrllimited (bool | int | str) – Control-limit tri-state (false, true, or auto).

  • cranklength (float | None) – Slider-crank length [m]. Required for slider-crank targets.

  • ctrl (float) – Initial control value, with the same units as ctrlrange.

  • custom_attributes (dict[str, Any] | None) – Additional registered mujoco:actuator attributes.

Returns:

The mujoco:actuator row index.

newton.actuators.InputProcessorBase#

class newton.actuators.InputProcessorBase[source]#

Bases: object

Base class for actuator input processors.

An input processor transforms the inputs of an actuator before they reach the drive. The inputs are the simulation state the drive reads (positions, velocities) and the commands (target positions, target velocities, feedforward). An Actuator runs its processors in list order; each processor receives the inputs returned by the previous one.

Subclasses must override resolve_arguments() and process(). Stateful subclasses also override is_stateful(), state() and update_state().

class Inputs(positions, velocities, target_pos, target_vel, feedforward, pos_indices, vel_indices, target_pos_indices, target_vel_indices, sim_positions, sim_velocities)#

Bases: object

Actuator inputs passed through the processor chain.

Each actuator slot i reads positions[pos_indices[i]], velocities[vel_indices[i]], target_pos[target_pos_indices[i]], target_vel[target_vel_indices[i]] and feedforward[target_vel_indices[i]]. A processor that replaces a target array with one entry per slot also replaces its index array. A processor keeps vel_indices and the shape of velocities: drives also use those indices for joint_qd-shaped custom inputs. Actuator.step raises ValueError otherwise.

Return the transformed actuator inputs.

Return a copy of inputs made with dataclasses.replace(); do not modify inputs in place. To read a joint other than the actuated one, index Inputs.sim_positions and Inputs.sim_velocities: earlier processors may have replaced Inputs.positions and Inputs.velocities.

JOINT_PARAMS: ClassVar[set[str]] = {}#

Names of parameters that reference a joint.

add_actuator() accepts a joint index or a joint label for each of these parameters, or None for the actuated joint. The joint must be a single-DOF joint of the same type as the actuated joint. It passes the joint to the constructor as two index arrays: <name>_indices into joint_qd-shaped arrays and <name>_pos_indices into joint_q-shaped arrays.
